## About / درباره

**RITM V** is a rebranded, fully re-themed build of the v2rayN client.

- Complete UI/UX overhaul — neon-violet dark theme + matching light theme
- Animated startup splash and shell transitions
- New application and tray icon set
- One-click links to the project's GitHub and Telegram channel

**RITM V** یک نسخه بازبرندشده با رابط کاربری کاملاً جدید است:

- تم تیره بنفش نئونی + تم روشن هماهنگ
- صفحه لودینگ انیمیشنی و ترنزیشن‌های نرم
- ست آیکون جدید برای برنامه و سینی سیستم
- دسترسی سریع به گیت‌هاب و کانال تلگرام از پایین پنجره

## Build from source

```bash
git clone https://github.com/RITM-Fre/RITM-V.git
cd RITM-V
dotnet build RITMV/RITMV.sln -c Release
```

Requires the **.NET 10 SDK** (see `RITMV/Directory.Build.props`).
